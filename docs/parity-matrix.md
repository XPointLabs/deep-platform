## Launch-Critical Scope

1. Protocol zero-regression: wire, groups, onion, regression artifacts.
2. Backend services parity: storage/file/push без compatibility-only зависимости в production path.
3. Router production transport: no-mock release validation, failover, degraded-mode readiness.
4. Client runtime parity: onboarding/recovery, 1:1, groups, attachments, avatars/profile image, push lifecycle на Android/iOS/Desktop.
5. Desktop parity inside MAUI: launch-critical desktop UX/runtime сценарии без отдельного клиентного форка.
6. Platform matrix e2e: обязательный Android+iOS+Windows gate с артефактами.
7. Security/compliance, observability и release discipline как release-blocking gates.

## Post-GA Scope

1. Desktop UX polish и platform-specific convenience-функции вне launch-critical сценариев.
2. Расширенные chaos/load кампании сверх минимального phase-exit набора.
3. Дополнительная compliance automation beyond mandatory release gate.
4. Нефункциональные улучшения UX/perf, не влияющие на launch-critical path.
