# Deep / XPoint

Предрелизный мессенджер с общим клиентским ядром и доставкой через сеть XNode. Этот репозиторий фиксирует совместный срез исходников Git-пинами дочерних проектов.

- [Спецификация](docs/architecture/README.md) — как устроена система, где находится код и какие сценарии подтверждены.
- [Текущий спринт](docs/NEXT-SPRINT.md) — открытый блокер, следующий шаг и критерии приёмки.
- [Правила работы](AGENTS.md) — границы изменений и проверки.
- [Запуск локального контура](deep-devops/README.md) и [документация для пользователей и операторов](xpoint-docs/README.md).

Для работы с кодом откройте спецификацию, затем инструкцию выбранного репозитория. Точные форматы и векторы перечислены в [реестре протокола](docs/architecture/PROTOCOL-REGISTRY-V1.md).
